# ssforward.github.io

Personal/portfolio site for SSForward, hosted on GitHub Pages.

## Tech Stack

- HTML5 / CSS3 (custom properties, Grid, Flexbox)
- [Bootstrap 5.3](https://getbootstrap.com/) — MIT License
- [Font Awesome 6 Free](https://fontawesome.com/) — MIT / CC BY 4.0
- [GLightbox](https://biati-digital.github.io/glightbox/) — MIT License
- Vanilla JavaScript (no jQuery)

## Structure

```
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── img/
    ├── bg1.jpg
    ├── favicon.png
    ├── apple-touch-icon.png
    └── portfolio/
```

## Development

Static site — open `index.html` directly in a browser or serve with any static file server:

```bash
npx serve .
```
